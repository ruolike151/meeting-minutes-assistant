# 交互原型

产品设计文档对应的可操作前端原型。**纯前端，无后端**，数据全部来自 `mock-data.js`。

## 运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖、无需构建。

```powershell
start index.html
```

## 可以试的操作

| 操作 | 说明 |
| --- | --- |
| 点示例问题 | 四个入口分别演示查询会议内容、查询发言人、定位发言原话、跨会议汇总 |
| 点回答里的引用 chip | 右侧切到「原声」，自动跳转并高亮对应的发言片段 |
| 输入框右侧回形针 | 选择本地音频，走一遍「标准化 → 转写 → 声纹 → 生成纪要」的处理流程 |
| 直接拖音频到对话区 | 同上，拖拽上传 |
| 左侧会议库 | 切换会议，对话范围会自动限定到该场会议 |
| 右侧「待确认」标签 | 处理低置信度条目，确认或忽略 |
| 右侧「待办」标签 | 勾选完成状态，会同步到导出的 CSV |
| 右上「导出」 | 真实下载纪要 Markdown、待办 CSV、对话记录 |
| 左下角月亮/太阳 | 切换深色与浅色主题 |
| 「新建对话」 | 清空会话，回到欢迎页 |

## 试着问这些

- 这场周会定了什么？
- 王强一共答应了哪些事？
- 谁提到了活动弹窗的问题？
- 这三场会有什么风险？

## 自测

```powershell
node selftest.js
```

覆盖数据完整性、检索层、回答引擎、导出与前端资源一致性，共 44 项检查，不需要浏览器。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构：会议库 / 对话区 / 详情面板 三栏 |
| `styles.css` | 设计令牌、组件样式、动效与响应式 |
| `mock-data.js` | 3 场模拟会议：片段、纪要、待办、风险 |
| `app.js` | 意图路由、检索、回答生成、渲染、导出 |
| `selftest.js` | 无浏览器依赖的自测脚本 |

## 与正式版的关系

这是**视觉与交互原型**，用来确认产品最终的呈现方式。正式版按《产品设计文档》实现：
正式版前端为 FastAPI + 原生前端（无构建），沿用本原型的三栏布局与设计令牌；
语音转写与声纹识别接入感知层，大模型调用 LLM API，
编排层用 LangGraph 状态图，检索层替换为「关键词 + 向量 + RRF 融合 + 重排」混合检索，数据落 SQLite。

原型里模拟的部分集中在 `app.js` 的三个函数，正式版替换为后端接口：

- `buildAnswer()` → `POST /api/chat`（LangGraph 状态图：意图路由与工具编排）
- `processAudio()` → `POST /api/audio` + `GET /api/tasks/{id}/events`（SSE 进度）
- `searchSegments()` → 检索层（不再由前端本地检索）
